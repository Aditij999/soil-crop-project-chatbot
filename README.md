## Project Structure

```
soil_crop_project/
│
├── data/
│   └── crop_fertilizer_data.csv       ← Kaggle dataset (N, P, K, pH, Crop, Fertilizer)
│
├── models/                            ← Auto-created; stores trained .pkl files
│   ├── crop_model.pkl                 ← Phase I classifier (generated by crop_model.py)
│   └── yield_model.pkl               ← Phase II regressor (generated by modules/yield_model.py)
│
├── modules/
│   ├── __init__.py
│   ├── soil_adjustment.py             ← Module 1: Computes nutrient gaps (Ideal − Current)
│   ├── fertilizer_recommendation.py   ← Module 2: Rule-based fertilizer mapping
│   └── yield_model.py                 ← Module 3: Trains + saves yield regression model
│
├── outputs/                           ← JSON reports auto-saved here after each pipeline run
│
├── crop_model.py                      ← Trains and saves crop_model.pkl (run once)
├── pipeline.py                        ← Main pipeline — connects all modules
├── app.py                             ← Streamlit web UI
└── README.md
```

## Setup & Run (Step-by-Step)

### 1. Install dependencies
```bash
pip install pandas numpy scikit-learn joblib streamlit plotly
```

### 2. Train the crop recommendation model (Phase I)
```bash
python crop_model.py
```
This generates `models/crop_model.pkl`.

### 3. Train the yield prediction model (Phase II)
```bash
python modules/yield_model.py
```
This generates `models/yield_model.pkl`.

### 4. Run the full pipeline (console output)
```bash
python pipeline.py
```

### 5. Launch the Streamlit web app
```bash
streamlit run app.py
```

## What Each Module Does

| Module | File | Type | Output |
|--------|------|------|--------|
| Crop Recommendation | `crop_model.py` | ML (Random Forest Classifier) | Top 5 crops + probabilities |
| Soil Adjustment | `modules/soil_adjustment.py` | Formula-based (Δ = Ideal − Current) | Nutrient gap + action |
| Fertilizer Recommendation | `modules/fertilizer_recommendation.py` | Rule-based system | Fertilizer name + dosage |
| Yield Prediction | `modules/yield_model.py` | ML (Random Forest Regressor) | Expected yield in kg/ha |
| Full Pipeline | `pipeline.py` | Orchestration | JSON report in outputs/ |
| Web UI | `app.py` | Streamlit | Interactive dashboard |

## Resume Description (Copy-Paste Ready)

**Soil Nutrient Analysis for Crop Planning and Fertilizer Recommendation**  
*Python · scikit-learn · pandas · Streamlit · Random Forest*

- Built a 4-module decision support system for precision agriculture targeting Black Soil regions of Western Maharashtra
- Trained a Random Forest Classifier (99% accuracy) to recommend optimal crops from N, P, K, pH, temperature, and rainfall inputs
- Designed a rule-based Soil Adjustment Engine computing nutrient gaps (Δ = Ideal − Current) with actionable increase/decrease/optimal flags
- Implemented a structured Fertilizer Recommendation module mapping multi-nutrient deficiencies to specific fertilizers (Urea, DAP, MOP, Lime)
- Developed a yield regression model (Random Forest, R² = 0.93) predicting expected output in kg/ha
- Deployed an end-to-end interactive web application using Streamlit with real-time sliders, Plotly charts, and auto-generated JSON reports
